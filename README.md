A short, funny rant generator: `main.py` writes one fixed, deterministic rant about an everyday annoyance — an office printer that only jams five minutes before a deadline (271 characters) — to `/output/entry.txt`, with a built-in guard that refuses to write unless the text is 1–400 characters.

## Run it

```sh
python3 main.py
```
